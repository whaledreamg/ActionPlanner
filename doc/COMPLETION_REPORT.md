- 坐标系显示

**SimulationWidget**:
- URDF文件扫描和加载

### 4. 时间轴编辑器 (85%)
**TimelineModel**:

- 片段管理(添加/删除/查询)

**TimelineEditor**:
- PR风格可视化时间轴

- 片段绘制(颜色、标签、时间、插值类型)
- 鼠标交互(选择、拖动、双击编辑)

### 5. 插值引擎 (70%)
**InterpolationEngine**:
- 线性插值

- 14轴同步插值(左臂7+右臂7)

### 6. 实时控制播放 (80%)

- 精确时间同步

### 7. 文件I/O (100%)

## 📝 Qt5/Qt6兼容性

代码已通过条件编译兼容Qt5.15+和Qt6.2+:

```cpp
#if QT_VERSION >= QT_VERSION_CHECK(5, 15, 0)
    // Qt5.15+ / Qt6代码
#else
    // 老版本Qt5代码
#endif
```

主要差异:
- `QOpenGLWidget`: Qt6需要显式添加`openglwidgets`模块
- `QAbstractSocket::error()` → `errorOccurred()`
- `QMouseEvent::x()/y()` → `position().x()/y()`

## 🚀 快速开始

### 编译 (Qt6)
```bash
cd /home/gxh/workspace/project/ActionPlanner
/home/gxh/Qt/6.8.3/gcc_64/bin/qmake
make -j4
```

### 运行
```bash
LD_LIBRARY_PATH=/home/gxh/Qt/6.8.3/gcc_64/lib:$LD_LIBRARY_PATH ./ActionPlanner
```

### 使用流程
1. **连接机器人**: 输入IP并点击"连接"
2. **使能机械臂**: 切换到左/右臂标签页并点击"使能"
3. **JOG微调**: 使用+/-按钮调整关节角度
4. **创建片段**: 点击"添加片段",输入标签和时长
5. **编辑动作**: 双击片段设置起始/结束角度
6. **保存序列**: 点击"保存"导出JSON文件
7. **播放轨迹**: 点击"播放"执行动作序列
