# UI美化更新说明

## 更新内容

已对动作规划器进行全面UI美化,采用现代化深色主题设计。

### 主要改进

#### 1. **主窗口 (MainWindow)**
- 深色主题配色方案 (#0A0D12 主背景)
- 优化菜单栏和状态栏样式
- 增加快捷键支持 (Ctrl+O, Ctrl+S, Ctrl+Q)
- 更清晰的布局间距

#### 2. **机器人控制面板 (RobotControlPanel)**
- **颜色体系**:
  - 表面层级: #0F131C, #161D2B, #1E2636 (递进深度)
  - 主要动作按钮: #38BDF8 (亮蓝色)
  - 危险操作按钮: #E94560 (红色)
  - 文本颜色: #E8E9ED (主), #9BA3B4 (次要)

- **组件优化**:
  - 分组框带圆角和边框 (border-radius: 8px)
  - 输入框聚焦时高亮边框
  - Tab标签页样式优化,选中状态清晰
  - 滚动条自定义样式
  - 状态指示带颜色编码 (未连接灰色, 连接中黄色, 已连接绿色)

- **按钮分类**:
  - 连接/使能: 亮蓝色主题
  - 失能: 红色警告主题
  - 普通操作: 中性深色主题

#### 3. **3D仿真窗口 (SimulationWidget)**
- 深色OpenGL渲染背景 (#161D2B)
- 下拉框和按钮圆角化设计
- FPS显示使用等宽字体
- 操作提示信息框(绿色系)
- 标题使用品牌色 (#38BDF8)

#### 4. **时间轴编辑器 (TimelineEditor)**
- 工具栏按钮图标化 (▶ 播放, ➕ 添加, 🗑 删除, 💾 保存, 📁 加载)
- 主要操作按钮区分:
  - 播放按钮: #6EE7B7 (绿色)
  - 添加按钮: #38BDF8 (蓝色)
  - 删除按钮: #E94560 (红色)
- 时间轴画布圆角容器样式
- 优化布局间距和padding

### 设计原则

1. **色彩阶梯**: 5-7层表面深度,从近黑到中灰
2. **功能色彩**:
   - 蓝色 (#38BDF8): 主要操作/品牌色
   - 绿色 (#6EE7B7): 成功/播放
   - 红色 (#E94560): 危险操作/删除
   - 黄色 (#E9A568): 警告/进行中
3. **圆角统一**: 按钮6px, 容器8px
4. **字体**: "Segoe UI", "Microsoft YaHei", sans-serif
5. **间距**: 8px/12px 网格系统
