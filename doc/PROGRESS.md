# 动作规划器 - 开发进度

## 已完成的功能模块

### ✅ 1. 项目框架 (100%)
- Qt QWidget应用程序结构
- qmake项目配置
- 主窗口三栏布局(左:控制面板 / 中:3D仿真 / 下:时间轴编辑器)
- 菜单栏和状态栏

### ✅ 2. 机器人连接与控制 (100%)
- **RobotConnection**: TCP Socket通信(端口9001)
- JSON协议消息封装
- 机器人列表查询、连接、使能/去使能
- 状态订阅(`robotState/sub`)实时推送关节角度
- **RobotControlPanel**: 
  - 左右臂独立控制面板
  - 7轴关节实时显示(角度/TCP位置)
  - JOG微调控制(+/- 按钮,400ms心跳维持)
  - "获取当前角度"按钮(用于时间轴编辑)

### ✅ 3. URDF解析与3D仿真 (90%)
- **URDFLoader**: 
  - 使用TinyXML2解析URDF文件
  - 提取Link(名称、位置、Mesh文件路径)
  - 提取Joint(名称、类型、父子link、旋转轴、限位)
- **RobotRenderer**: 
  - 基于QOpenGLWidget的3D渲染器
  - 简化的正向运动学计算
  - 球体表示关节,圆柱体表示连杆
  - 交互式相机控制(鼠标左键旋转、滚轮缩放)
  - 坐标系显示(XYZ轴)
- **SimulationWidget**:
  - URDF文件扫描和加载(自动搜索urdf_dualarm文件夹)
  - 下拉选择URDF文件
  - 实时更新机器人姿态(连接到RobotStateManager)

**待完善**: 
- 完整的DH参数正向运动学
- STL mesh文件加载与渲染
- 碰撞检测

### ✅ 4. 时间轴编辑器 (85%)
- **TimelineModel**: 
  - 片段(Segment)数据结构(标签、开始时间、持续时间、开始/结束关节角度、插值类型)
  - 添加/删除/查询片段
  - 总时长计算
- **TimelineEditor**: 
  - PR风格的可视化时间轴
  - 时间标尺(刻度和秒数标记)
  - 片段绘制(背景色、标签、时间范围、插值类型、关节预览)
  - 鼠标交互(单击选择、双击编辑、拖动移动)
  - 添加片段对话框(输入标签和持续时间)
  - 删除选中片段
  - JSON文件保存/加载(完整序列配置)

**待完善**:
- 详细的片段编辑对话框(手动输入14轴角度)
- 拖动调整持续时间(边缘控制点)
- 片段碰撞检测和自动排列
- 播放进度指示器(红色播放头)

### ✅ 5. 插值与滤波引擎 (70%)
- **InterpolationEngine**:
  - 线性插值(`linearInterpolate`)
  - 三次样条插值(`cubicSplineInterpolate`)
  - 支持14轴同步插值(左臂7轴+右臂7轴)

**待完善**:
- S曲线加减速
- 速度和加速度滤波(巴特沃斯、中值滤波)
- 轨迹平滑优化

### ✅ 6. 实时控制播放 (80%)
- **RealtimeController**:
  - 进入/退出实时控制模式(`realtime/startControl` / `stopControl`)
  - 高频轨迹执行(4ms控制周期,250Hz)
  - 精确时间同步(QElapsedTimer)
  - 根据时间插值生成目标关节角度
  - 通过TCP Socket发送关节指令
  - 播放进度信号(`playbackStarted` / `playbackProgress` / `playbackFinished` / `playbackError`)

**待完善**:
- UDP实时控制接口(替换TCP以降低延迟)
- 暂停/恢复功能
- 实时速度调节(0.5x ~ 2x)

### ✅ 7. 文件I/O (100%)
- **FileIO**: 
  - JSON格式保存动作序列(版本、总时长、所有片段、关节角度)
  - JSON格式加载动作序列
  - 错误处理

## 已知问题

1. ⚠️ **正向运动学简化**: 当前3D渲染使用简化的FK(仅堆叠offset),不精确
2. ⚠️ **实时控制协议**: 使用TCP而非UDP,可能存在延迟
3. ⚠️ **片段拖动**: 拖动片段移动时未更新模型,仅在视觉上拖动
4. ⚠️ **缺少碰撞检测**: 片段可以相互重叠
